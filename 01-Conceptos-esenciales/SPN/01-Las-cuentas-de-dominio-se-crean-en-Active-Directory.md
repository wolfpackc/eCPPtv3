# Las cuentas de dominio se crean en Active Directory

Las **cuentas de dominio**, tanto las utilizadas por personas como las utilizadas como cuentas de servicio tradicionales, se crean y gestionan en **Active Directory**.

Ejemplos:

```text
EMPRESA\Edu
EMPRESA\Maria
EMPRESA\svc_sql
EMPRESA\svc_backup
```

Todas ellas son cuentas del dominio.

> Matiz importante: esto no se aplica a las **cuentas locales** de un equipo, que se crean y gestionan en ese equipo concreto.
